# Forma 3D

**A 3D modeling and experimentation environment for the web.**

Forma 3D is a browser-based 3D creation project inspired by professional tools such as Blender. Developed through vibe coding, it combines programming, experimentation, and AI-assisted development to create an accessible environment for 3D modeling.

The project focuses on 3D objects, materials, shaders, lighting, physics, scripting, and project management.

---

## Overview

Forma 3D provides a 3D workspace directly in the browser, without requiring a traditional desktop installation.

### Main Features

- 3D object creation and editing.
- Scene visualization and camera controls.
- Object color and material customization.
- Realistic and anime-inspired visual styles.
- Configurable graphics quality.
- Lighting and reflection experiments.
- Physics simulation.
- JavaScript scripting through f3Dge.
- Project importing and exporting.

## 3D Viewport

The viewport is the main workspace for interacting with 3D objects.

Features include:

- 3D scene visualization.
- Camera movement and rotation.
- Object inspection.
- Material previews.
- Different visual styles.
- Configurable rendering resolution.

## Materials and Colors

Forma 3D includes material customization options.

Available experiments include:

- Standard materials.
- Glass-like materials.
- Reflective surfaces.
- Mirror-like materials.
- Custom object colors.
- Hexadecimal color input.

Example: `FF0000` represents red.

## Graphics and Shaders

The application includes different visual styles:

- **Realistic:** designed for more natural-looking materials and lighting.
- **Anime:** uses stylized lighting and cel-shading effects.

Graphics quality can be adjusted in the application settings.

Available resolution multipliers:

- 0.75x
- 1x
- 1.25x
- 1.5x
- 2x

Higher settings may require more processing power.

## Lighting and Reflections

Forma 3D includes lighting and material experiments designed to improve the appearance of 3D scenes.

These include:

- Environment-based reflections.
- Reflective surfaces.
- Glass-like transparency.
- Material highlights.
- Shadow effects.

Some advanced visual effects are approximations rather than physically accurate ray tracing.

## Physics

The application includes physics experimentation for 3D objects, allowing users to explore simulated physical interactions.

## f3Dge Code

Forma 3D includes its own scripting environment called **f3Dge**.

It allows users to write and execute JavaScript-based scripts to experiment with objects and scene behavior.

The scripting interface includes API helpers for objects, input, scenes, logic, rendering, and other systems.

Its API is inspired by game-engine workflows and does not represent complete compatibility with Blender Game Engine.

## Project Files

Forma 3D uses the `.f3Dge` project format.

Project files are designed to preserve scene information and associated scripts.

Supported workflows include:

- Exporting projects.
- Importing previously exported projects.
- Saving projects locally.
- Working with scripts and 3D scenes.

## Technology

Forma 3D is a browser-based application built using:

- HTML
- CSS
- JavaScript
- Three.js
- Cannon.js

The application is hosted on Vercel.

## Development

Forma 3D was created through **vibe coding**, an iterative development approach where ideas are transformed into working features through collaboration with AI-assisted programming.

The project evolves through experimentation, testing, debugging, and continuous refinement.

Its inspiration comes from traditional 3D software, especially Blender, while maintaining its own interface, features, and identity.

## Project Status

Forma 3D is an evolving project. Features, interface elements, and internal systems may change as development continues.
